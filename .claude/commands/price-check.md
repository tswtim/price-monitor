# Проверка цен конкурентов

Запусти сбор цен с сайтов конкурентов, проанализируй результаты и выведи отчёт.

## Инструкции

1. Запусти скрипт сбора данных:
```bash
cd price-monitor && python -m monitor.cli --run
```

2. Проанализируй полученные результаты:
   - Какие сайты работают, какие нет
   - Минимальная, средняя, максимальная цена за 100 г
   - Позиция нашей цены относительно рынка
   - Самые дешёвые аналоги с указанием сайта и бренда

3. Если есть сохранённая история, сравни с предыдущей проверкой:
```bash
cd price-monitor && python -m monitor.cli --history
```

4. Отметь, если цена конкурентов изменилась более чем на 5%.

5. Если какой-то сайт не отвечает или блокирует — сообщи об этом отдельно.

## Параметры

- Наш продукт: Икра горбуши (120 г) — см. `monitor/config.py`
- Наша цена: см. `data/user_price.json`
- Если нужно изменить параметры поиска — отредактируй `monitor/config.py`

## Формат вывода

Выведи:
1. Таблицу сравнения (сортируй по цене за 100 г)
2. Статистику: мин / средняя / макс цена за 100 г
3. Позицию нашей цены относительно рынка
4. Предупреждения об изменениях (>5%)
5. Рекомендацию: стоит ли корректировать цену
